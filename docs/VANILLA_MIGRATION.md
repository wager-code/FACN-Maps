# 专用模组地图的纯原版迁移方法与损失

## 先区分四个结果

1. 地形可加载。
2. 地图初始化、首波、后期波次、胜负均有实现。
3. 主要规则保留但用原版单位近似代替，属于改编。
4. 完整保留原 MOD 体验；缺少该 MOD 的模型/武器/脚本时通常做不到。

禁止把“删报错 import / 返回 nil / 清空波表 / 忽略 CreateUnit 失败”描述成无损修复。原模组版应作为独立来源保留，改编使用独立地图身份与路径，尊重作者信息与授权。

## 大量单位表替换的正确顺序

1. 识别每个单位在活动表的角色、科技、阵营与陆/海/空类别；别只靠编号前缀。
2. 检查所有创建点、技能、强化、模型/效果导入、死亡逻辑和最终目标，不只替换波表。
3. 每个原单位记录原功能、候选单位、理由、损失、原版可用证据及需要测试的分支。
4. 处理空池：不能筛掉所有缺失单位后让随机选取访问空表，也不能让核心波次默默消失。
5. 保持或明确记录对波次时间、数量、资源与胜负的改变；不得暗中降低玩法复杂度后称等价。
6. 若地图本身没有波次系统（Swarm/Eternals），须获取对应模组合法源码或重新设计。新写的通用生存模式不等于恢复原模式。
7. DDDX RPG 要逐英雄、逐等级/强化/技能、特殊建筑和终局单独回归。只让首波运行不足以证明已摆脱模组。
