# AI 维护《最高指挥官：钢铁联盟》现有地图：修复手册

> 范围：**只研究、诊断、修复已有地图**，并在用户明确需要、目标版本可行时增加可选高级设置。**不研发软件、不生成新地形、不自动发布地图。**
>
> 目标优先级：Steam 原版 SCFA 无 FAF 依赖运行（若原玩法允许） > 完整保留原始玩法 > 在目标大厅可见且生效的设置 > 单机/多人正确性。FAF 版作为源码与兼容对照；需要时另行保留 FAF 专用版。
>
> 证据标记：本文件中的 GitHub 社区修复记录属于“外部报告”，不是对任何用户地图的修复/实测结果。2026-10-15 文档研究；完整游戏兼容性须以目标安装和日志证明。

## 0. AI 修图任务的入口（固定顺序）

1. 读取 `AGENTS.md`、`README.md`、`docs/KNOWN_MAP_FINDINGS.md`、`docs/STEAM_FA_COMPATIBILITY.md`、`docs/VANILLA_MIGRATION.md`、`docs/TEST_AND_RELEASE.md`，再读本文件、`API_EVIDENCE_MATRIX.md`、`ADVANCED_OPTIONS_REPAIR_GUIDE.md`、`COMMUNITY_REPAIR_CASES.md`。
2. 确认用户提供的**当前**地图源文件与目标运行环境；仓库里的旧审计是历史快照，不得假设本次本地地图存在或哈希未变。
3. 原始地图包只读备份，记录每个文件 SHA-256、原作者、版本、地图目录、实际目标游戏构建、相关 MOD 和测试方法。分支或独立目录操作，不覆写原版。
4. 对整个地图**递归建依赖图**，先静态审查、锁定根因，再提出最小补丁及影响说明；不得“批量修复”未复现的问题。
5. 修复与新选项分成两个独立补丁/提交；先修原玩法，再做可选功能。无授权不得自动删除/合并旧图。
6. 按“静态 → 对照蓝图及资源 → 地图大厅 → 单人 → 多人 → 后期波次与胜负”逐层验证，**未跑游戏不能写通过**。
7. 更新已知问题、接口差异、功能库、测试矩阵和维护日志；给出回滚步骤。

## 1. 地图文件与依赖图

| 对象 | 正确职责 | AI 审查问题 |
|---|---|---|
| `.scmap` | 二进制地形、高度、地表分层、贴花、物件、预览等 | 数据格式、资源路径、是否编辑器保存导致数据损失 |
| `*_scenario.lua` | 地图显示名、`map_version`、地图路径、`size`、玩家槽位、`ExtraArmies` | 目录与引擎虚拟路径是否一致；普通玩家槽是否混入 NPC |
| `*_save.lua` | `MASTERCHAIN`、markers、路径/资源标记、初始军队单位 | 缺失路点、非法出生点、预置 `INITIAL` 或 `WRECKAGE` 错误 |
| `*_script.lua` | `OnPopulate`、`OnStart`、AI/波次、胜负逻辑 | 线程/胜利是否终止；空槽处理；时序和游戏事件 |
| `*_options.lua` | 用户选项定义 | `key/pref/default/values[].key`、实际消费位置、是否被目标大厅读取 |
| `src/`、`vendor/`、`*_tables.lua` 等 | 独立波表、命令表、辅助库 | 所有 `import()` 与动态路径，不能遗漏 |
| `.luac` | 编译脚本 | 对应 LuaPlus/引擎版本；没有源码不要假称可安全改写 |

地图 `.scmap` 的 `v56/v60` 是**地图二进制格式**，不是“Steam/FAF 两种版本”的对应关系。参考 [FAF Mapping Guidelines](https://github.com/FAForever/wiki-pages/blob/main/faf-version-guidelines.md)：FAF Editor 可读存 v56/v60；旧 GPG Editor 仅支持 v56；降存 v56 可能丢失 skybox/其他数据。**禁止为修 Lua 逻辑先重存地形**。

`.scmap` 相同不代表地图玩法相同。必须比较 `_save.lua`、`_script.lua`、`_options.lua` 与递归引入的 `WaveTable`、`WaveOrders`、胜负/阵营规则。本仓库 Horde EE / Aeon Fixed 的历史审计即为反例。

## 2. Steam/FAF 兼容检查，不靠猜测 API

1. 建立两个独立清单：Steam 安装 `gamedata/*.scd` 与 FAF 实际使用的资源包、Lua 模块、单位蓝图、纹理/物件路径（记录所用版本）。**不能假设 FAF 有的内容就是 Steam 原版内容**。
2. 针对每条 `import` 检查 VFS 路径/大小写、挂载位置、同名冲突与目标版本真实存在性。支持不同平台、不同加载器的情况分别标记。
3. 对所有活动单位引用从 `_save.lua`、脚本、独立波表、条件分支和动态生成点搜集 ID，对照**真实蓝图索引**。ID 并非固定“几字母+四数字”，例如部分 MOD 有更长编号；避免把注释/颜色/无效分支当必需依赖。
4. 分清 **FAF 本身差异**、**第三方 SIM MOD**、**仅资源素材**、**可选 MOD 支持**、**必须由外部游戏模式提供的玩法**。不能因为地图能打开就宣称生存玩法保留。
5. 遇到无法实现的 FAF 特性：优先保留 FAF 原版；另做用户明确接受功能损失的 Steam 候选版，并列出损失与对比。切忌删波表或屏蔽异常后宣布完成。
6. 对 Lua 用符合目标 FA/LuaPlus 方言的编译/加载方式检验；不能将标准 Lua 5.x 结果视为实机证明；UI API 与 sim API 的环境必须核对。

具体接口/验证来源见 [API_EVIDENCE_MATRIX.md](API_EVIDENCE_MATRIX.md)。

## 3. 常见故障 → 修复动作（先证据后改动）

| 故障表现 | 优先定位 | **候选**修复（须确认根因） | 回归 |
|---|---|---|---|
| 地图大厅不可见/加载了另一张图 | `_scenario.lua` 的 `map/save/script`、路径、目录名、版本、冲突 ID | 修正受影响的虚拟路径与实际文件名；不要重绘地图 | 目标客户端识别、预览、单机进入 |
| FAF 图在 Steam 缺贴图/物件 | `.scmap` 的 strata/decals/props、水面纹理路径及目标资源包 | 更正路径，或选合法且可用的 Steam 素材替代；记录视觉损失 | 地形/水面/贴花对比截图 |
| 另存后纹理消失 | 内嵌硬编码路径、波浪/水坡道贴图、编辑器保存差异 | 先恢复原二进制；必要时在副本更新相关路径 | 保存前后数据差异及实机 |
| Lua 开局报错 | 首条错误堆栈、import、nil army、初始化调用次数 | 对应 API/空槽/时序做最小修正 | 1/2/满员，默认选项 |
| 中后期停止刷兵 | 全波表、后期蓝图、线程、路点、胜负终止分支 | 修实际出错单位/线程/标记，**不删整个后期阶段** | T1/T2/T3/T4、末波或无尽 |
| 选项出现但没效果 | `_options.lua` 声明与 `ScenarioInfo.Options` 使用路径 | 统一消费路径、合法默认值、正确类型；先确认大厅支持 | 修改前后选项日志 + 游戏可见效果 |
| 添加 ACU/工程师后输赢异常 | 预置 ACU、死亡监听、军队胜负、单位归属 | 明确原胜负规则，避免新增 ACU 无意变成额外生命 | 部分/全部 ACU 死亡、目标死亡 |
| 多人不同步 | 同名地图版本/文件哈希、UI/sim 代码、随机数/线程分支 | 固定一致的文件与 sim 行为，禁每客户端重复产生单位 | 参与者完整内容 SHA-256 + 同步日志 |
| 大地图、后期卡顿 | 重复 `ForkThread`、无间隔循环、全图单位扫描、单位上限 | 修终止条件、扫描频率、队列/刷怪节奏 | 典型后期压力测试 |

典型公共 Issue 与具体复现条件详见 [COMMUNITY_REPAIR_CASES.md](COMMUNITY_REPAIR_CASES.md)；对本库已发现的真实地图问题请查 [KNOWN_MAP_FINDINGS.md](KNOWN_MAP_FINDINGS.md)。

## 4. “地图修好”所需的最小证据

- **静态确认**：准确文件+行号、触发条件、对照资源/蓝图/接口、可重复的失败案例；只是分析不表示修好。
- **已修改待实测**：补丁、差异、备份哈希、编译/数据用例；未运行目标游戏。
- **Steam 单人通过**：记录目标可执行文件/构建、MOD 状态；大厅可见、选项显示、设置被脚本读取且真实改变行为、完整关键阶段和胜负结果。
- **Steam 多人通过**：多人混合阵营、空槽、退出、不同设置与同步日志；要测试完整地图哈希一致。
- **FAF 测试另记**：FAF 上通过不能代替 Steam 的状态；现有 `AGENTS.md` 状态词汇不扩展，FAF 证据在测试环境字段补记。
- 缺少可运行环境或授权 → 明确写“阻塞/未验证”；没有实际运行结果不得把预测当完成。

## 5. 后续可选高级设置

用户明确提出，且**目标大厅能显示、传值、sim 可执行**时，再增加：
- 开局额外指挥官 ACU／支援指挥官 SACU（不同单位，不可混淆）；
- 工程师等级 T1/T2/T3；
- 跟随玩家种族／指定 UEF、Aeon、Cybran、Seraphim／混合种族；
- 额外数量按白名单档位可选，包括 **0 = 原始默认**；
- 全部玩家共享选项 vs 单独为每个有效玩家槽位配置（后者须目标大厅确实支持）；
- 如仅修改地图内 AI 单位的阵营，应与**改变玩家大厅种族**明确分离。

详细案例、单位蓝图、教程与风险矩阵见 [ADVANCED_OPTIONS_REPAIR_GUIDE.md](ADVANCED_OPTIONS_REPAIR_GUIDE.md)。
