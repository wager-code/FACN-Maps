# FACN-Maps 当前状态

> 状态基准：2026-10-21。本文是**全仓全局数量、维护对象区分和总体验证状态的唯一权威入口**。这些数据来自仓库现有维护记录，不代表本次重新扫描了用户电脑或重新运行了游戏。

## 1. 冲突时按什么顺序判断

1. **当前任务中用户最新的明确指令**：决定本次允许做什么、不能做什么。
2. **用户已确认的长期要求**：[生存地图用户要求与执行约定](USER_REQUIREMENTS_SURVIVAL_MAPS_2026-10-21.md)。
3. **本文**：决定全局维护包/安装地图数量、总体状态、已知限制和未完成事项。
4. **目标地图卡片及对应最新专项报告**：决定某张地图的具体版本、文件哈希、根因和测试证据。使用前应核对报告是否对应当前文件。
5. **通用操作规则**：[仓库根目录 AGENTS.md](../AGENTS.md)。
6. **历史报告和维护日志中的旧状态**：只用于追溯，不自动代表当前状态。

如果最新指令、状态页、地图卡片或专项报告仍互相冲突，不要把两种方案叠加执行。先比对日期、目标对象和文件哈希；仍无法确定时，停止有风险的写入并报告冲突。

## 3. 当前已知限制与未完成事项

- 仓库以知识文档、地图卡片、专项报告和辅助工具为主；完整地图源码/资源并未全部提交到仓库。
- 静态检查、普通 Lua 解析、目标 LuaPlus 隔离加载、实际菜单加载器测试、游戏内测试、多人测试、内容中心扫描、云端发布是不同验证层级。
- 安装地图最近的 Atoll/Brainsucka 发布结构预检记录报告了文件/路径核验通过，但**尚未**据此确认真实内容中心扫描、云端上传、Steam 游戏运行或多人验证通过。
- Sea Fleet 的“没问题了”是用户对该次问题的实测反馈，不扩展为完整波次矩阵、多人或全部地图的通过结论。
- 具体未解决问题应在对应地图卡片、专项报告和测试清单中记录；本文只维护全局状态，不复制每张地图的长篇历史。
